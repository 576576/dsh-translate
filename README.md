# dsh-translate — DeepSeek Harness 翻译模式

![DSH bundle spec 0.2.1-rc.2](docs/badges/dsh-bundle.svg)

中文 | [English](docs/en/README.md)

为 [DeepSeek Harness](https://github.com/deepseek-ai)（Web UI 与桌面版通用）添加「翻译模式」：一个只返回译文的 Agent 预设，以及输入框工具行上的语言方向与翻译风格控件。

## 功能

- **翻译模式预设**：新建会话时选择「翻译模式」，模型只输出译文——不加解释、不加引号、不用代码围栏，保留原文的换行、编号与代码块。
- **输入框工具行**（仅翻译模式会话显示）：`[源语言▾] [⇄] [目标语言▾] [风格设置▾]`，外观与原生模型、权限选择器一致。
- **语言菜单**：可搜索或直接输入自定义语言（`+` 添加、可删除）；选中项带对勾；关闭「允许源与目标同语言」后，两个菜单互相排除。
- **目标语言「自动」**：默认选项，按句判断翻译方向，见下节。
- **风格菜单**：填写翻译风格后自动保存，也可保存为预设、一键应用或删除。
- **设置页**：设置 → 翻译模式，可配置优先源/目标语言、是否允许源与目标相同、管理风格预设。
- 界面文案与插件管理页的标题/描述均支持 18 种语言。

## 目标语言「自动」

源语言与目标语言默认都是「自动」。目标语言为「自动」时逐句判断：

| 原文语言 | 界面语言 | 译为 |
|---|---|---|
| 不是界面语言 | 任意 | 界面语言 |
| 是界面语言 | 不是英语 | 英语 |
| 是英语 | 英语 | 中文 |

## 安装

本仓库是 DSH bundle，使用插件管理器安装（目标填本仓库的绝对路径）：

```
plugin_manager({ action: "install_bundle", target: "<本仓库绝对路径>" })
```

安装后在「设置 → 插件」启用插件，新建会话即可在预设选择器中选择「翻译模式」。

维护与实现说明见 [docs/agent/README.md](docs/agent/README.md)。
